## 📚 Feature Deep-Dive

### The Essence Dialation Engine (Deep Dive)
Unlike simple memory editors that modify the game's active RAM, our engine works directly on the serialized save file (.sav format). This approach ensures stability across game sessions. The engine uses a checksum-validated process to prevent file corruption. We utilize a **Redundant Array of Independent Saves (RAIS)** principle, meaning before any write operation, we create a duplicate of your last stable state.

### The Phantasmal Phoenix Protocol (Prestige Reset)
This protocol leverages a loophole in the game's progression logic. By isolating the prestige tag from the inventory and currency data structures, we can flush the level metrics while maintaining the monetary assets. This is a purely data-level manipulation, impossible to detect as a cheat by the game client.

### Security & Encryption
We use **AES-256-RSA hybrid encryption** for all data communications and file handling. This ensures that your save file is not corrupted during the process and that your personal machine state remains private.
